# Task-Manager
A Java-based console application designed to help students manage and prioritize academic tasks.

## Features
- Add tasks with deadlines, difficulty, and estimated hours
- Mark tasks as complete
- Automatic urgency calculation
- Task sorting based on urgency
- Due date warnings
- File persistence using text files

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File I/O
- Java Collections Framework
- LocalDate API

## How to Run
1. Clone the repository
2. Open the project in your Java IDE
3. Run `Menu.java` or `Main.java`
